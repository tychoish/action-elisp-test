A streamlined suite of composite GitHub Actions to execute ERT test suites, configurable linters, and code coverage analysis for Emacs Lisp packages with zero configuration boilerplate.

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=elisp-ci= eliminates repetitive shell boilerplate from Emacs package CI workflows by encapsulating:
- **Automatic GPG Keyring & Archive Setup**: Preconfigures GNU ELPA, NonGNU ELPA, MELPA, and ELPAish snapshot archives. Automatically fetches and imports the ELPAish GPG public keyring for cryptographic signature validation, with seamless unsigned archive fallback.
- **Universal Input Parsing**: All list inputs accept either YAML structures/lists (bullet items or flow sequences) or lists of strings (whitespace, comma, tab, or newline-delimited).
- **Configurable Quality Linters**: Byte-compilation (with warnings-as-errors), =checkdoc= docstring linting, =package-lint=, and =relint= with granular required/advisory failure gates.
- **Coverage Reporting & UI Summary**: Measures code coverage with =under-cover= in SimpleCov, LCOV, Coveralls, or text formats, and renders summary tables directly to GitHub Actions Job Summaries (=$GITHUB_STEP_SUMMARY=).

* Actions
:PROPERTIES:
:CUSTOM_ID: actions
:END:

** Test Runner
:PROPERTIES:
:CUSTOM_ID: test-runner
:END:

Runs ERT or ELPAish test suites with automatic archive, keyring, and dependency bootstrapping.

*Action reference*: =tychoish/elisp-ci@main=

*** Options

| Input                 | Default                                                     | Description                                                  |
|-----------------------+-------------------------------------------------------------+--------------------------------------------------------------|
| =dependencies=        | =""=                                                        | ELPA package dependencies (YAML list or list of strings).    |
| =test-files=          | ="test/test-*.el"=                                          | Test files or globs to load and execute (YAML list or string).|
| =load-paths=          | ="."=                                                       | Directories to prepend to =load-path= (YAML list or string). |
| =archives=            | ="gnu nongnu melpa elpaish"=                                | Enabled package archives (YAML list or list of strings).     |
| =unsigned-archives=   | ="elpaish"=                                                 | Fallback unsigned archive whitelist (YAML list or string).   |
| =keyring-url=         | ="https://tychoish.github.io/elpaish/elpaish-keyring.gpg"=   | Remote GPG keyring for ELPAish signature verification.        |
| =runner=              | ="ert"=                                                     | Test runner engine (=ert= or =elpaish=).                     |

*** Basic Configuration

Run test suites using default settings:

#+begin_src yaml
- name: Run Tests
  uses: tychoish/elisp-ci@main
#+end_src

*** Full Configuration (All Defaults Specified)

All options explicitly configured with their default values:

#+begin_src yaml
- name: Run Tests (All Defaults Specified)
  uses: tychoish/elisp-ci@main
  with:
    dependencies: ""
    test-files: "test/test-*.el"
    load-paths: "."
    archives: "gnu nongnu melpa elpaish"
    unsigned-archives: "elpaish"
    keyring-url: "https://tychoish.github.io/elpaish/elpaish-keyring.gpg"
    runner: "ert"
#+end_src

List inputs can also be passed as YAML lists / structures:

#+begin_src yaml
- name: Run Tests (YAML List Configuration)
  uses: tychoish/elisp-ci@main
  with:
    dependencies:
      - compat
      - transient
    load-paths:
      - .
      - lisp
    test-files:
      - test/test-*.el
      - test/integration/test-*.el
    archives:
      - gnu
      - nongnu
      - melpa
      - elpaish
#+end_src

** Linter
:PROPERTIES:
:CUSTOM_ID: linter
:END:

Runs byte-compilation, =checkdoc=, =package-lint=, and =relint= across source files with customizable failure thresholds.

*Action reference*: =tychoish/elisp-ci/lint@main=

*** Options

| Input                 | Default                                                     | Description                                                  |
|-----------------------+-------------------------------------------------------------+--------------------------------------------------------------|
| =dependencies=        | =""=                                                        | Dependencies to install prior to linting (YAML list/string). |
| =target-files=        | ="*.el"=                                                    | Source files or globs to analyze (YAML list or string).      |
| =load-paths=          | ="."=                                                       | Directories to prepend to =load-path= (YAML list or string). |
| =linters=             | ="byte-compile checkdoc"=                                   | Active linters (YAML list or list of strings).               |
| =required-linters=    | ="byte-compile checkdoc"=                                   | Linters that block build on failure (YAML list or string).   |
| =fail-on-warning=     | ="true"=                                                    | Treat byte-compiler warnings as fatal errors.                |
| =archives=            | ="gnu nongnu melpa elpaish"=                                | Enabled package archives (YAML list or list of strings).     |
| =unsigned-archives=   | ="elpaish"=                                                 | Fallback unsigned archive whitelist (YAML list or string).   |
| =keyring-url=         | ="https://tychoish.github.io/elpaish/elpaish-keyring.gpg"=   | Remote GPG keyring URL.                                      |

*** Basic Configuration

Run default linters (=byte-compile= and =checkdoc=):

#+begin_src yaml
- name: Lint Source Files
  uses: tychoish/elisp-ci/lint@main
#+end_src

*** Full Configuration (All Defaults Specified)

All options explicitly configured with their default values:

#+begin_src yaml
- name: Lint Source Files (All Defaults Specified)
  uses: tychoish/elisp-ci/lint@main
  with:
    dependencies: ""
    target-files: "*.el"
    load-paths: "."
    linters: "byte-compile checkdoc"
    required-linters: "byte-compile checkdoc"
    fail-on-warning: "true"
    archives: "gnu nongnu melpa elpaish"
    unsigned-archives: "elpaish"
    keyring-url: "https://tychoish.github.io/elpaish/elpaish-keyring.gpg"
#+end_src

Enabling extended linters via YAML structures:

#+begin_src yaml
- name: Lint Source Files (Extended Linters)
  uses: tychoish/elisp-ci/lint@main
  with:
    dependencies:
      - compat
      - transient
    target-files: "*.el"
    linters:
      - byte-compile
      - checkdoc
      - package-lint
      - relint
    required-linters:
      - byte-compile
      - checkdoc
    fail-on-warning: "true"
#+end_src

** Code Coverage
:PROPERTIES:
:CUSTOM_ID: coverage
:END:

Instruments source files using =under-cover=, executes test suites, exports coverage artifacts, and outputs a formatted markdown summary into =$GITHUB_STEP_SUMMARY=.

*Action reference*: =tychoish/elisp-ci/coverage@main=

*** Options

| Input                 | Default                                                     | Description                                                  |
|-----------------------+-------------------------------------------------------------+--------------------------------------------------------------|
| =dependencies=        | =""=                                                        | Dependencies to install prior to test run (YAML list/string).|
| =source-files=        | ="*.el"=                                                    | Source files to instrument for coverage (YAML list/string).  |
| =test-files=          | ="test/test-*.el"=                                          | ERT test files or globs to run (YAML list or string).        |
| =load-paths=          | ="."=                                                       | Directories to prepend to =load-path= (YAML list or string). |
| =report-format=       | ="simplecov"=                                               | Format: =simplecov=, =lcov=, =coveralls=, or =text=.         |
| =output-file=         | ="coverage.json"=                                           | Target file path for generated coverage data.                |
| =archives=            | ="gnu nongnu melpa elpaish"=                                | Enabled package archives (YAML list or list of strings).     |
| =unsigned-archives=   | ="elpaish"=                                                 | Fallback unsigned archive whitelist (YAML list or string).   |
| =keyring-url=         | ="https://tychoish.github.io/elpaish/elpaish-keyring.gpg"=   | Remote GPG keyring URL.                                      |

*** Basic Configuration

Instrument default files and export SimpleCov report:

#+begin_src yaml
- name: Measure Test Coverage
  uses: tychoish/elisp-ci/coverage@main
#+end_src

*** Full Configuration (All Defaults Specified)

All options explicitly configured with their default values:

#+begin_src yaml
- name: Measure Test Coverage (All Defaults Specified)
  uses: tychoish/elisp-ci/coverage@main
  with:
    dependencies: ""
    source-files: "*.el"
    test-files: "test/test-*.el"
    load-paths: "."
    report-format: "simplecov"
    output-file: "coverage.json"
    archives: "gnu nongnu melpa elpaish"
    unsigned-archives: "elpaish"
    keyring-url: "https://tychoish.github.io/elpaish/elpaish-keyring.gpg"
#+end_src

Coverage workflow uploading LCOV tracefile to Codecov:

#+begin_src yaml
- name: Measure Test Coverage (LCOV)
  uses: tychoish/elisp-ci/coverage@main
  with:
    source-files:
      - "my-package.el"
      - "lisp/*.el"
    test-files:
      - "test/test-*.el"
    report-format: "lcov"
    output-file: "coverage/lcov.info"

- name: Upload Coverage to Codecov
  uses: codecov/codecov-action@v4
  with:
    files: coverage/lcov.info
#+end_src

* Supported Linters & Quality Gates
:PROPERTIES:
:CUSTOM_ID: supported-linters
:END:

The =lint= sub-action supports four integrated analyzers:

1. **=byte-compile=**: Runs Emacs batch byte-compilation. When =fail-on-warning: true= is set, compiler warnings (unresolved variables, obsolete functions, missing requires) fail the build.
2. **=checkdoc=**: Validates standard Emacs Lisp docstring style (sentence casing, capitalization of parameter names, header comments).
3. **=package-lint=**: Validates compliance with ELPA/MELPA packaging standards (automatically installed if enabled).
4. **=relint=**: Scans regular expressions for syntax errors and inefficiencies (automatically installed if enabled).

*Gating Modes*:
- **=linters=**: Determines which linters are executed.
- **=required-linters=**: Determines which linters produce fatal, build-breaking failures vs advisory output.

* Coverage Formats & Reporting
:PROPERTIES:
:CUSTOM_ID: coverage-reporting-options
:END:

When measuring coverage with =under-cover= via =tychoish/elisp-ci/coverage=, the following =report-format= options are supported:

| Format       | Output File Defaults | Use Case & Tooling Compatibility                                              |
|--------------+----------------------+-------------------------------------------------------------------------------|
| =simplecov=  | =coverage.json=      | JSON format compatible with SimpleCov, Code Climate, Codacy, and SonarQube.  |
| =lcov=       | =lcov.info=          | Standard LCOV tracefile for =codecov/codecov-action= and IDE coverage gutters.|
| =coveralls=  | =coveralls.json=     | Coveralls API payload format.                                                 |
| =text=       | =coverage.txt=       | Human-readable plain text summary.                                            |

*Automatic GitHub Actions Summary*:
In addition to the exported artifact file, the coverage runner automatically appends a markdown summary table to =$GITHUB_STEP_SUMMARY=, rendering coverage status directly in the GitHub Actions run overview.

* Example Workflow
:PROPERTIES:
:CUSTOM_ID: example-workflow
:END:

A complete CI matrix workflow running linting, ERT tests, and code coverage:

#+begin_src yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest
    container: silex/emacs:${{ matrix.emacs_version }}-ci
    strategy:
      matrix:
        emacs_version: ["29.4", "30.2"]
    steps:
      - uses: actions/checkout@v5

      - name: Lint Source Code
        uses: tychoish/elisp-ci/lint@main

      - name: Run ERT Tests
        uses: tychoish/elisp-ci@main

      - name: Measure Code Coverage
        if: matrix.emacs_version == '30.2'
        uses: tychoish/elisp-ci/coverage@main
        with:
          report-format: "lcov"
          output-file: "coverage/lcov.info"
#+end_src
