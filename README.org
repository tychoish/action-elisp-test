A streamlined suite of composite GitHub Actions to execute ERT test suites, configurable linters, and code coverage analysis for Emacs Lisp packages with zero configuration boilerplate.

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=action-elisp-test= eliminates repetitive 30-line shell scripts from Emacs package CI workflows by encapsulating:
- **Automatic GPG Keyring & Archive Setup**: Preconfigures GNU ELPA, NonGNU ELPA, MELPA, and ELPAish snapshot archives. Automatically fetches and imports the ELPAish GPG public keyring for cryptographic signature validation, with seamless unsigned archive fallback.
- **Universal Input Parsing**: Supports whitespace-separated strings, comma-delimited lists, multiline strings, and YAML list bullet formats (`- item`) for all list inputs.
- **Configurable Quality Linters**: Byte-compilation (with warnings-as-errors), `checkdoc` docstring linting, `package-lint`, and `relint` with granular required/advisory failure gates.
- **Coverage Reporting & UI Summary**: Measures code coverage with `under-cover` in SimpleCov, LCOV, Coveralls, or text formats, and renders summary tables directly to GitHub Actions Job Summaries (`$GITHUB_STEP_SUMMARY`).

* Workflows & Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:

** 1. ERT Test Runner (=tychoish/action-elisp-test@main=)
:PROPERTIES:
:CUSTOM_ID: usage-test-runner
:END:

#+begin_src yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest
    container: silex/emacs:${{ matrix.emacs_version }}-ci
    strategy:
      matrix:
        emacs_version: ["29.4", "30.2"]
    steps:
      - uses: actions/checkout@v5

      - name: Run ERT Tests (YAML List Inputs)
        uses: tychoish/action-elisp-test@main
        with:
          dependencies: |
            - compat
            - transient
          load-paths: |
            - .
            - lisp
          test-files: |
            - test/test-*.el
            - test/integration/test-*.el
#+end_src

** 2. Linter & Byte-Compiler (=tychoish/action-elisp-test/lint@main=)
:PROPERTIES:
:CUSTOM_ID: usage-linting
:END:

Run byte-compilation and docstring checks, optionally enabling `package-lint` and `relint`:

#+begin_src yaml
      - name: Lint Source Files
        uses: tychoish/action-elisp-test/lint@main
        with:
          dependencies: "compat transient"
          target-files: "*.el"
          linters: |
            - byte-compile
            - checkdoc
            - package-lint
          required-linters: "byte-compile checkdoc"
          fail-on-warning: "true"
#+end_src

** 3. Code Coverage (=tychoish/action-elisp-test/coverage@main=)
:PROPERTIES:
:CUSTOM_ID: usage-coverage
:END:

Instrument source files and export coverage reports:

#+begin_src yaml
      - name: Measure Test Coverage
        uses: tychoish/action-elisp-test/coverage@main
        with:
          source-files: "my-package.el"
          test-files: "test/test-*.el"
          report-format: "lcov"
          output-file: "coverage/lcov.info"

      - name: Upload Coverage to Codecov
        uses: codecov/codecov-action@v4
        with:
          files: coverage/lcov.info
#+end_src

* Supported Linters & Quality Gates
:PROPERTIES:
:CUSTOM_ID: supported-linters
:END:

The =lint= sub-action supports four integrated analyzers:

1. **=byte-compile=**: Runs Emacs batch byte-compilation. When =fail-on-warning: true= is set, any compiler warnings (unresolved variables, obsolete functions, missing requires) fail the build.
2. **=checkdoc=**: Validates standard Emacs Lisp docstring style (sentence casing, capitalization of parameter names, header comments).
3. **=package-lint=**: Validates compliance with ELPA/MELPA packaging standards (automatically installed if enabled).
4. **=relint=**: Scans regular expressions for syntax errors and inefficiencies (automatically installed if enabled).

*Gating Modes*:
- **=linters=**: Determines which linters are executed.
- **=required-linters=**: Determines which linters produce fatal, build-breaking failures vs advisory output.

* Coverage Reporting & Rendering Options
:PROPERTIES:
:CUSTOM_ID: coverage-reporting-options
:END:

When measuring coverage with =under-cover= via =tychoish/action-elisp-test/coverage=, the following =report-format= options are supported:

| Format       | Output File Defaults | Use Case & Tooling Compatibility                                              |
|--------------+----------------------+-------------------------------------------------------------------------------|
| =simplecov=  | =coverage.json=      | JSON format compatible with SimpleCov, Code Climate, Codacy, and SonarQube.  |
| =lcov=       | =lcov.info=          | Standard LCOV tracefile for =codecov/codecov-action= and IDE coverage gutters.|
| =coveralls=  | =coveralls.json=     | Coveralls API payload format.                                                 |
| =text=       | =coverage.txt=       | Human-readable plain text summary.                                            |

*Automatic GitHub Actions Summary*:
In addition to the exported artifact file, the coverage runner automatically appends a markdown summary table to =$GITHUB_STEP_SUMMARY=, rendering coverage status directly in the GitHub Actions run overview.

* Configuration Reference
:PROPERTIES:
:CUSTOM_ID: configuration-reference
:END:

** Test Runner (=action.yml=)

| Input                 | Default                                                     | Description                                                  |
|-----------------------+-------------------------------------------------------------+--------------------------------------------------------------|
| =dependencies=        | =""=                                                        | ELPA package dependencies (space-separated or YAML list).    |
| =test-files=          | ="test/test-*.el"=                                          | Test files or globs to load and execute.                     |
| =load-paths=          | ="."=                                                       | Directories to prepend to =load-path=.                       |
| =archives=            | ="gnu nongnu melpa elpaish"=                                | Enabled package archives.                                    |
| =unsigned-archives=   | ="elpaish"=                                                 | Fallback unsigned archive whitelist.                         |
| =keyring-url=         | ="https://tychoish.github.io/elpaish/elpaish-keyring.gpg"=   | Remote GPG keyring for ELPAish signature verification.        |
| =runner=              | ="ert"=                                                     | Test runner engine (=ert= or =elpaish=).                     |

** Linter (=lint/action.yml=)

| Input                 | Default                      | Description                                                  |
|-----------------------+------------------------------+--------------------------------------------------------------|
| =dependencies=        | =""=                         | Dependencies to install prior to linting.                    |
| =target-files=        | ="*.el"=                     | Source files to analyze.                                     |
| =load-paths=          | ="."=                        | Directories to prepend to =load-path=.                       |
| =linters=             | ="byte-compile checkdoc"=    | Active linters: =byte-compile=, =checkdoc=, =package-lint=, =relint=. |
| =required-linters=    | ="byte-compile checkdoc"=    | Linters that block the build on failure.                     |
| =fail-on-warning=     | ="true"=                     | Treat byte-compiler warnings as fatal errors.                |
| =archives=            | ="gnu nongnu melpa elpaish"= | Enabled package archives.                                    |
| =unsigned-archives=   | ="elpaish"=                  | Fallback unsigned archive whitelist.                         |
| =keyring-url=         | ="https://tychoish.github.io/elpaish/elpaish-keyring.gpg"=   | Remote GPG keyring URL.                                      |
